Personal Mail Mirror

A private workstation utility that makes a one-way archival copy of email from an owner-controlled Yahoo mailbox into a dedicated Gmail account.

What the application does

  • Connects to the owner's Yahoo mailbox using a separate app password and read-only IMAP.
  • Copies selected message content, original dates, headers, and attachments into the owner's dedicated Gmail account through the Gmail API.
  • Creates Gmail labels corresponding to source folders and keeps local synchronization metadata to reduce duplicate imports.
  • Runs periodically on the owner's own computer. The source Yahoo mailbox remains unchanged.

Why Google account access is requested

Google OAuth is used solely to authorize a private Gmail destination for archived messages. The application currently requests the gmail.modify scope, which is broader than the operations this utility performs. The implemented mirror imports messages, creates labels and adds labels to imported messages. It is not designed to send email, delete Gmail messages, or delete or modify Yahoo messages.

Scope and limitations

This application is for personal use by its owner. It is not a public email service and offers no public sign-up. It is an additive archive rather than a bidirectional mailbox synchronization system: source-side deletions, moves, and later read/unread changes are not necessarily reflected in the Gmail copy. The workstation must be on and connected for synchronization to run.

Data and privacy

The copied mail is stored in the owner's Gmail account. Local configuration holds authentication credentials, and a local database stores message identifiers and synchronization state. This public website does not log into either mailbox, host messages, or request credentials.

Read the privacy policy for information about data access, retention, sharing and revocation, and the terms of use for operating limitations.
